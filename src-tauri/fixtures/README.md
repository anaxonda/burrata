These seven compact Ogg Opus fixtures are generated from a synthetic sine tone, not a copyrighted recording or a library asset. See `manifest.json` for the exact encoder command, byte hashes, Q7.8 mutations, CRC handling, and reference decode measurements. `src/opus_decoder_capability.rs` validates fixture structure and page CRCs before starting the configured decoder.

The three base fixtures are compiled into the decoder-capability probe; four derived OpusTags fixtures exercise strict tag parsing. Only these seven manifest-listed synthetic files are exceptions to the repository audio-file ignore rule. `make_tag_fixtures.py` derives the four tag variants from the documented synthetic base.
