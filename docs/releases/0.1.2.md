# Burrata 0.1.2

This desktop update improves playback recovery, browsing and compact desktop controls.

- Correct macOS/Windows media-control task ownership for cross-platform builds.
- Bound prolonged buffering and stalled seeks, retain playback position during source recovery, and keep actionable failure reasons visible.
- Preserve queue occurrence identity and navigation state through playback, paging and restarts.
- Add shared sorting and duration filters, source-aware controls, provider browsing and managed Spotify/YouTube sessions.
- Refine desktop toolbars, context menus and playback-bar layout, including narrow desktop windows.
- Add explicit verified recording-identity preparation for Spotify sources, using exact catalog relationships and recording-scoped artist credits while preserving saved tags.

Provider availability and catalog matching remain dependent on the recording, region and provider. An identity verification does not guarantee a playable source. Spotify playlist creation remains deferred; YouTube writeback remains disabled pending review. Experimental decoder and storage changes remain off by default.

Release artifacts must pass the tagged workflow's platform builds and installed-package smoke checks before publication. Current verification evidence is tracked in `todo.md` and the dated performance/desktop reports; this file alone is not a successful release receipt.
