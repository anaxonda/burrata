# Burrata 0.1.2

This desktop update improves playback recovery, browsing and compact desktop controls.

The main downloads contain the platform installers, Chromium extension, signed Firefox extension and checksums. Required runtime helpers are already bundled with the installers. [Supporting downloads](https://github.com/anaxonda/burrata/releases/tag/untagged-26f63c0ec9ce9d663846) contain optional helper updates, corresponding dependency sources, licenses and verification records; ordinary users do not need them.

- Correct macOS/Windows media-control task ownership for cross-platform builds.
- Handle canonical Windows drive paths correctly when browsing local folders.
- Bound prolonged buffering and stalled seeks, retain playback position during source recovery, and keep actionable failure reasons visible.
- Preserve queue occurrence identity and navigation state through playback, paging and restarts.
- Add shared sorting and duration filters, source-aware controls, provider browsing and managed Spotify/YouTube sessions.
- Refine desktop toolbars, context menus and playback-bar layout, including narrow desktop windows.
- Add explicit verified recording-identity preparation for Spotify sources, using exact catalog relationships and recording-scoped artist credits while preserving saved tags.

Provider availability and catalog matching remain dependent on the recording, region and provider. An identity verification does not guarantee a playable source. Spotify playlist creation remains deferred; YouTube writeback remains disabled pending review. Experimental decoder and storage changes remain off by default.

Validation is complete for the draft prerelease: [platform CI](https://github.com/anaxonda/burrata/actions/runs/39106398365) and [tagged release checks](https://github.com/anaxonda/burrata/actions/runs/39106996579) pass. Native library tests pass on Linux (1,092), macOS (1,058) and Windows (1,018), with 21 intentionally ignored per platform. The produced DEB, macOS DMG and Windows NSIS installers pass installed-app smoke checks, including bundled tools, media fixtures, native-host communication and frontend/MCP startup. RPM and AppImage are built and checksummed; they are not independently installation-smoked.

All five installer inventories match uploaded hashes and sizes. Separate checksum manifests cover the seven main downloads and 86 supporting files; all match GitHub asset digests. Chromium and AMO-signed Firefox companions remain version 0.2.1. The exact tagged-source local app is running with its queue and playback settings preserved and no playback-bar geometry findings.

This remains a **non-public draft prerelease**. OS security prompts, public signing/notarization and fresh-machine product qualification are outside these smoke checks. [Acceptance evidence](https://github.com/anaxonda/burrata/blob/main/docs/performance-results/2026-10-18-platform-release/README.md).
