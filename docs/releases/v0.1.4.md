# Burrata v0.1.4

Playback reliability and desktop consistency update.

- Improve recording/source verification, preserve complete artist credits and verified source connections, and avoid wasting extraction attempts on weaker candidates.
- Keep startup, cancellation and retry work within a shared deadline. Add 20/30/45-second startup timeout choices in Playback settings.
- Recover stalled radio and finite playback without treating a single inaccessible URL as a missing recording.
- Fix native seek ranges, cancellation while waiting for response headers, queued decoder failures and duplicate queue restoration. Native playback remains an internal experimental mode; WebView playback remains the default.
- Improve radio identification metadata/artwork, track menus, album navigation, search rows, filters and desktop playback-bar spacing.
- Include patched streaming dependency sources, licenses and patch notes with supporting downloads.

Install: [macOS, Windows and Linux instructions](https://github.com/anaxonda/burrata/blob/main/docs/install.md).
Optional browser extensions: [Firefox](https://github.com/anaxonda/burrata/blob/main/extension/README.md#firefox) · [Chrome / Chromium / Edge](https://github.com/anaxonda/burrata/blob/main/extension/README.md#chrome-chromium-and-edge).

Choose the main installer for your platform. Extensions are available alongside installers; technical supporting packages are optional.

This update migrates the library database from schema 9 to 10. Preserve a backup before upgrading if you need to return to v0.1.3; that version cannot open a migrated database.

Known limits: provider availability and complete catalog coverage vary. Some obscure recordings still lack a verified source. Exploratory Matthew startup takes about 12–16 seconds; the five-second startup p95 target is not established. Physical Mac/Windows native audio, device changes and sleep/wake remain unqualified. Spotify playlist work remains paused, YouTube writeback stays off, and alternative extractor/codec experiments are not enabled.
