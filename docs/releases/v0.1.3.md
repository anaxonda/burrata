# Burrata v0.1.3

Playback matching and desktop browsing improvements, with a simpler browser companion.

- Fix false unavailable results caused by artist-credit punctuation and missing imported durations. Use bounded YouTube Music discovery and fresh identity verification while preserving version and excerpt checks.
- Fix YouTube fallback extraction selecting a token-dependent client without its managed token provider.
- Add explicit recording-credit verification using complete Spotify/MusicBrainz artist IDs and a selected MusicBrainz recording; preserve saved tags and keep verification requests off the playback path.
- Fix WebView resume timing out when audio has resumed but the browser leaves its play promise pending; require media progress on the same playback source.
- Simplify the companion to page import, put diagnostics under More options, and move optional browser-assisted access into Connections. In-app sign-in remains the preferred connection method.
- Import public YouTube videos and playlists from the active browser tab without signing in, including the current playlist-card layout and honest partial-import reporting.
- Open Spotify and YouTube playlist browsing in main Search; keep profile pages scoped to their owner without duplicate browsing-mode controls.
- Render Spotify artist/profile artwork, recover safely from failed artwork URLs, and correct light-theme search contrast.
- Align artist and saved-playlist playback actions and buffering/paused feedback.
- Collapse individual search providers while retaining their loaded results and pagination. Hidden provider groups are excluded from search playback continuation.
- Add Burrata toolbar icons to Firefox and Chromium companions, including the isolated provider extension.

Choose the main installer for your platform. Browser companions are included alongside installers; supporting downloads are optional.

Spotify playlist work remains paused. YouTube writeback remains off. Experimental codecs and storage indexes remain disabled. This update does not claim complete provider catalog coverage or statistical playback performance qualification.
