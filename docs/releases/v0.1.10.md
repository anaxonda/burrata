# Burrata v0.1.10

This release fixes artist discographies being discarded when a MusicBrainz response exceeds the cache size limit. It also improves YouTube playback recovery and adds diagnostic evidence for the remaining Mac playback failures.

- Artist release lists use smaller metadata requests. Cache-write failures no longer discard valid provider responses. Failed pages have a retry action and duplicate warnings are removed.
- YouTube recovery has a dedicated same-recording attempt within the existing startup deadline. Eligible denied streams move straight to recovery, and validated Google video CDN redirects are supported.
- Diagnostic revision 2 includes public source page links, redacted extractor error summaries and exit codes, client/token/expiry indicators, proxy/CA configuration presence, redirect hops, and correlated startup outcomes. Credentials and signed stream URLs are excluded. EJS availability is explicitly unknown when it cannot be checked.
- Optional reproduction details let a tester include browser, alternate-network and VPN observations in the report. These are manual observations, not automated comparisons.

For the Mac tester: install the Apple Silicon DMG, enable Playback diagnostics in Settings, clear existing events, reproduce one failure, then export the report before closing Burrata. Fill in optional reproduction details if those comparisons have been tried.

The underlying SoundCloud extractor failure and original YouTube authorization denials are still being investigated. This release does not claim those upstream causes are resolved. Hosted-runner installer checks do not replace qualification on the affected Mac/network.
