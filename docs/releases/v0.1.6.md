# Burrata v0.1.6

Candidate release notes. Publish only after the final runtime and installer checks recorded in the current goal audit pass.

- Improve recording matching for featured credits, artist aliases, transliterations and incomplete catalog metadata, while preserving explicit recording and version conflicts.
- Add an expanded Now Playing view with artwork, artist information, credits and queue access. Make shuffle, autoplay and repeat states clearer, with tooltips and persistent loading feedback.
- Add albums to an existing or new playlist, defaulting new playlist names to the album title. Improve playlist ordering, queue selection, search history and readable playlist exports.
- Preserve exact saved search sources during playlist downloads when artist metadata is missing. Keep source-reported tags separate from verified catalog identity.
- Improve album downloads, source fallback, Soulseek search recovery and coherent peer-folder selection. Optional cover-art failures no longer block audio downloads.
- Retain consistent audio recognition results even when no unique catalog match is available. Review and apply recognized artist, title and ISRC individually, preserving manually edited fields.
- Restore folder scrolling and reuse existing local metadata after verifying file integrity.
- Add editable radio stream URLs and optional capture of heard tracks into a chosen playlist.

Install: [macOS, Windows and Linux instructions](https://github.com/anaxonda/burrata/blob/main/docs/install.md).
Optional browser companions: [Firefox](https://github.com/anaxonda/burrata/blob/main/extension/README.md#firefox) · [Chrome / Chromium / Edge](https://github.com/anaxonda/burrata/blob/main/extension/README.md#chrome-chromium-and-edge).

Provider availability and metadata coverage vary. BPM/key estimates may be left blank when confidence is insufficient. Audio recognition does not always distinguish mixes or versions. Extended Monochrome lossless integration remains paused and is excluded from this release.
