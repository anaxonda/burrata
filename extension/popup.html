Import the current page

Public chart, playlist, and album metadata from supported pages.

Diagnostics save one sanitized public track row locally. Cookies, JSON scripts and forms are excluded. Nothing is uploaded.

Supported pages and import notes

Beatport, Traxsource, Shazam, Last.fm, Spotify playlists or albums, Bandcamp albums, and Bandcamp Discover pages.

Keep Burrata running. Spotify capture may scroll for up to 25 seconds and restores your position. Shazam and Last.fm preserve explicit ranks; Bandcamp Discover reads up to 20 rendered album cards. Verification requires your interaction.

App-driven imports request supported-site access only when enabled. Current-page import remains available if permission is declined.

How the session handoff works

The code expires after two minutes and works once. The SAPISID signing cookie is read only after both confirmations and sent directly to the app instance named by the code. Google mailbox data and other Google cookies are excluded.

Remove the connection in Burrata’s Connections settings.
