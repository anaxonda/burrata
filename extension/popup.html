Connections

Browser-assisted access

In-app sign-in in Burrata Settings → Connections is preferred. This optional mode lets Burrata use your signed-in browser session for provider requests and app-driven imports.

Grant site access when asked. You can still import the active page without enabling this mode.

To connect Spotify with this browser, enable access here, then choose Spotify → Connect in Burrata Settings → Connections. Burrata opens your Spotify tab to verify the signed-in account.

Pair a YouTube session with Burrata

This is a separate option for sending the selected YouTube session to the app. In Burrata Connections, create a pairing code for this instance.

How the session handoff works

The code expires after two minutes and works once. The SAPISID signing cookie is read only after both confirmations and sent directly to the app instance named by the code. Google mailbox data and other Google cookies are excluded.

Remove the connection in Burrata’s Connections settings.
