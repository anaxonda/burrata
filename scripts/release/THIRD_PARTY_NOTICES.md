# Third-party notices

This release bundles the following pinned tools. Exact versions, URLs, and archive checksums are in `locked-tools.json`; platform-specific binary/source checksums are in each `LOCKED_TOOLS-*.json` and `THIRD_PARTY_SOURCES.md`.

- Node.js 24.21.0 — MIT; the upstream `LICENSE` file is bundled beside the runtime.
- yt-dlp nightly 2026.10.10.233141 — the core source is Unlicense; the PyInstaller binary also contains GPLv3+ code and other third-party components. The matching source commit's `LICENSE` and `THIRD_PARTY_LICENSES.txt` are bundled.
- FFmpeg/ffprobe 8.1.3 — GPL-3.0-or-later build from the same SHA-256-pinned FFmpeg source on macOS, Linux, and Windows. Every target statically includes LAME 3.100 and Opus 1.6.1, enables zlib (pinned static zlib 1.3.2 on Linux/Windows and the macOS SDK zlib on Apple Silicon), and uses the shared locked feature profile for broad built-in audio decoding, common containers, PNG artwork, metadata, and chapters. TLS uses Apple Secure Transport on macOS, static OpenSSL 3.5.9 on Linux, and Windows Schannel on Windows. The matching FFmpeg/dependency source archives, upstream licenses, target build scripts, lock file, configuration, and source hashes accompany each target bundle. Windows binaries are built with the pinned-in-workflow MSYS2 MINGW64 toolchain; Linux and macOS use native toolchains. See `FFMPEG_LICENSE.txt`, `FFMPEG_BUILD_INFO.txt`, `FFMPEG_BUILD_CONFIGURATION.json`, `MEDIA_SOURCE_INVENTORY.json`, `build-recipe/`, and `THIRD_PARTY_SOURCES.md` for the exact build records.
- LAME 3.100 — LGPL-2.0-or-later; its source archive and upstream license accompany all media-tool bundles.
- Opus 1.6.1 — BSD-3-Clause; its source archive and upstream license accompany all media-tool bundles.
- zlib 1.3.2 — zlib License; its source archive and license accompany Linux and Windows media-tool bundles. macOS uses the system SDK zlib.
- OpenSSL 3.5.9 — Apache-2.0; statically linked into Linux FFmpeg/ffprobe, with its matching source archive and license bundled. Windows and macOS use their native TLS backends.
- Chromaprint/fpcalc 1.5.1 — official pinned upstream fpcalc assets are used on all three targets, with archive and extracted-binary hashes verified. Each platform tool bundle also carries the matching Chromaprint source archive, its upstream `LICENSE.md`, and the locally pinned LGPL-2.1 text.
- BgUtils POT Provider 2.0.2 — provider server and matching yt-dlp plugin from commit `26475e9d3665b972c4aeb83b4dbaafcf64b88438`; source and package lock files are retained in the resource bundle. Its plugin download is attached as a separately checksummed release asset.
- stream-download 0.24.4 — MIT OR Apache-2.0; the native application links the checked-in library with Burrata's sparse-seek gap-selection and pending-request cancellation patches. The supporting downloads contain `stream-download-0.24.4-burrata-patched.tar.gz`, both upstream license texts (`STREAM_DOWNLOAD_LICENSE_MIT.txt` and `STREAM_DOWNLOAD_LICENSE_APACHE.txt`) and `STREAM_DOWNLOAD_PATCHES.md`. `THIRD_PARTY_SOURCES.md` records the upstream package checksum and the exact patched archive checksum.

The Burrata source tree is distributed under GPL-3.0-or-later. See `THIRD_PARTY_SOURCES.md` for vendored native source inventory. Browser companion packages retain their own manifest and licensing metadata; Firefox is signed by AMO as unlisted and Chromium is supplied as a ZIP.
